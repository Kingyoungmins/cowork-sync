세상 배치 — 어떤 구조가 좋으세요?

캐릭터는 A안(말랑이)으로 확정. 이제 "어디에서 일하는지"를 어떻게 보여줄지 고릅니다. 장면 속 주황 말랑이(민수)가 지연에게 걸어가 부탁하는 모습이 반복됩니다.

1. 저장소 = 사무실, 파일 = 책상

저장소 하나가 사무실 한 칸. 책상마다 파일(또는 폴더) 이름표. 누가 어떤 파일의 어느 함수를 잡고 있는지 책상 위치로 바로 보입니다. 팀이 저장소 하나로 일할 때 가장 직관적.

2. 광장 + 저장소별 큰 테이블

말씀하신 그대로: 광장에 저장소마다 큰 테이블. 누가 어느 저장소에서 일하는지는 잘 보이지만, 같은 저장소 안에서 누가 어느 파일을 잡았는지는 말풍선으로만 보입니다.

3. 지도 + 사무실 확대 (추천)

왼쪽 작은 지도에 저장소마다 방이 하나씩(내 PC에 있는 cowork 저장소들), 오른쪽은 고른 방을 1번처럼 크게. 저장소 여러 개도, 파일 단위 움직임도 다 담깁니다.
